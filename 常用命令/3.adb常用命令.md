# adb 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 设备相关

| 命令 | 说明 |
| ---- | ---- |
| `adb devices` | 查看已连接设备 |
| `adb connect <ip:port>` | 连接网络设备 |
| `adb reboot` | 重启设备 |
| `adb -s <设备号> <命令>` | 指定设备执行命令 |

## 2. 应用相关

| 命令 | 说明 |
| ---- | ---- |
| `adb install xxx.apk` | 安装应用 |
| `adb uninstall <包名>` | 卸载应用 |
| `adb shell pm list packages` | 列出所有包名 |
| `adb shell am start -n <包名>/<Activity>` | 启动指定页面 |

## 3. 文件相关

| 命令 | 说明 |
| ---- | ---- |
| `adb push <本地> <设备路径>` | 电脑推文件到设备 |
| `adb pull <设备路径> <本地>` | 设备拉文件到电脑 |

## 4. 调试相关

| 命令 | 说明 |
| ---- | ---- |
| `adb logcat` | 查看日志 |
| `adb logcat -s <TAG>` | 过滤指定 TAG 日志 |
| `adb shell screencap /sdcard/1.png` | 截屏 |
| `adb shell screenrecord /sdcard/1.mp4` | 录屏 |
| `adb shell dumpsys activity top` | 查看当前 Activity 信息 |
