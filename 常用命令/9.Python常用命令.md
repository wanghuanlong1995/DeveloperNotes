# Python 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 运行相关

| 命令 | 说明 |
| ---- | ---- |
| `python xxx.py` | 运行脚本 |
| `python -m <模块名>` | 以模块方式运行 |
| `python -V` | 查看版本 |

## 2. 虚拟环境

| 命令 | 说明 |
| ---- | ---- |
| `python -m venv venv` | 创建虚拟环境 |
| `venv\Scripts\activate` | 激活（Windows） |
| `source venv/bin/activate` | 激活（Linux/macOS） |
| `deactivate` | 退出虚拟环境 |

## 3. pip 包管理

| 命令 | 说明 |
| ---- | ---- |
| `pip install <包名>` | 安装包 |
| `pip install -r requirements.txt` | 按清单安装 |
| `pip install <包名> -i https://pypi.tuna.tsinghua.edu.cn/simple` | 使用清华镜像安装 |
| `pip uninstall <包名>` | 卸载包 |
| `pip list` | 已安装包列表 |
| `pip freeze > requirements.txt` | 导出依赖清单 |
| `pip install --upgrade pip` | 升级 pip 自身 |
