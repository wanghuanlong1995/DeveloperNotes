## 1. Claude Code 常用命令

> 官方文档：<https://code.claude.com/docs/zh-CN/overview>

### 1.1 启动与会话（命令行）

| 命令 | 说明 |
| ---- | ---- |
| `claude` | 启动交互式会话 |
| `claude "任务描述"` | 带初始任务启动 |
| `claude -p "问题"` | 非交互模式执行并输出结果（适合脚本/管道调用） |
| `claude -c` | 继续当前目录最近一次会话 |
| `claude -r <名称或ID>` | 恢复指定会话（不带参数则打开会话选择器） |
| `claude -n "名称"` | 给会话命名，方便之后 `claude -r 名称` 恢复 |
| `claude --model sonnet` | 指定模型（`sonnet`/`opus`/`haiku` 或完整模型 ID） |
| `claude --effort high` | 设置推理力度：`low`~`xhigh`、`max` |
| `claude --permission-mode plan` | 以规划模式启动（先分析方案、不改代码） |
| `claude --dangerously-skip-permissions` | 跳过所有权限确认（谨慎使用） |
| `claude --add-dir ../其他目录` | 附加额外可读写的目录 |
| `claude -w feature-x` | 在独立 git worktree 中启动，适合并行开发 |
| `claude --bg "任务"` | 作为后台代理启动并立即返回终端 |
| `claude --agents '{"评审员":{"description":"...","prompt":"..."}}'` | 临时定义自定义子代理 |
| `claude --chrome` | 启用 Chrome 集成（网页自动化与测试） |
| `claude mcp add <名称> -- <命令>` | 添加 MCP 服务器 |
| `claude mcp list` | 列出已配置的 MCP 服务器 |
| `claude mcp remove <名称>` | 移除 MCP 服务器 |
| `claude update` | 升级 Claude Code |
| `claude -v` | 查看版本号 |

### 1.3 常用快捷键

| 快捷键 | 说明 |
| ---- | ---- |
| `Shift+Tab` | 循环切换权限模式：普通 → 自动接受编辑 → 规划模式 |
| `Alt+M` | Windows 部分终端下切换规划模式（Shift+Tab 不出现 Plan 时） |
| `Esc` | 中断 Claude 当前操作 |
| `Esc` `Esc` | 回退到历史消息重新编辑 |
| `Ctrl+C` | 取消当前输入；连按两次退出 |
| `Ctrl+D` | 退出会话 |
| `Ctrl+L` | 清屏 |
| `Ctrl+O` | 展开查看完整输出（transcript） |
| `Tab` | 补全文件/目录路径 |
| `Shift+Enter` | 输入换行（先用 `/terminal-setup` 配置终端） |
| `↑` / `↓` | 翻看输入历史 |

### 1.4 输入前缀技巧

| 前缀 | 说明 |
| ---- | ---- |
| `!命令` | 直接运行 shell 命令，输出自动进入对话上下文 |
| `@文件路径` | 快速引用文件/目录加入上下文 |
| `/技能a /技能b 任务` | 一条消息串联多个技能（最多 6 个） |

### 1.5 实用技巧

- **大改动先规划**：`Shift+Tab` 切到 Plan 模式（或 `claude --permission-mode plan`），确认方案后再动手
- **上下文管理**：`/context` 看占用大头，快满时 `/compact`；`/clear` 开新任务
- **项目记忆**：`/init` 生成 CLAUDE.md，用 `/memory` 持续补充项目规范和常用命令
- **并行工作**：让 Claude 派发子代理并行处理，`/tasks` 查看；跨文件大重构用 `/batch`
- **减少权限弹窗**：`/permissions` 手动加白名单，或 `/fewer-permission-prompts` 扫描历史自动生成
- **随时回滚**：每次编辑都有检查点，`/rewind` 或 `Esc Esc` 可回退代码和对话
- **脚本化调用**：`claude -p "..." --output-format json` 接入 CI/脚本，`--max-turns`/`--max-budget-usd` 控制成本

## 2. OpenClaw 常用命令

> 官方文档：<https://docs.openclaw.ai/cli>（中文版 <https://docs.openclaw.ai/zh-CN/cli>）

### 安装与初始化

| 命令 | 说明 |
| ---- | ---- |
| `openclaw onboard` | 引导式初始化（验证推理 → 网关/工作区/渠道/技能） |
| `openclaw setup` | 快速安装设置 |
| `openclaw setup --baseline` | 跳过引导，直接创建基础配置和工作区 |
| `openclaw configure` | 修改已有配置（模型授权、网关、渠道、插件、技能） |
| `openclaw update` | 升级 OpenClaw（也可用全局简写 `--update`） |
| `openclaw uninstall` | 卸载 |
| `openclaw reset` | 重置状态 |

### 网关与服务管理

| 命令 | 说明 |
| ---- | ---- |
| `openclaw gateway run` | 前台运行网关 |
| `openclaw gateway start / stop / restart` | 启动 / 停止 / 重启网关 |
| `openclaw gateway status` | 查看网关状态 |
| `openclaw gateway install / uninstall` | 安装 / 卸载网关系统服务 |
| `openclaw daemon status` | 查看守护服务状态（`install`/`start`/`stop` 等同网关服务） |
| `openclaw logs` | 查看日志 |
| `openclaw dashboard` | 打开控制面板（Control UI） |

### 状态与诊断

| 命令 | 说明 |
| ---- | ---- |
| `openclaw status` | 总体状态速览（`--json` 输出 JSON） |
| `openclaw status --usage` | 查看各模型供应商的用量/配额 |
| `openclaw health` | 健康检查 |
| `openclaw doctor` | 只读体检，输出健康报告（网关/渠道/插件/技能/模型路由） |
| `openclaw doctor --fix` | 体检并自动修复 |
| `openclaw doctor --check gateway` | 只检查指定目标（如 `gateway`、`channels`） |
| `openclaw triage` | 问题分诊 |
| `openclaw security audit` | 安全审计 |

### 模型管理

| 命令 | 说明 |
| ---- | ---- |
| `openclaw models list` | 列出可用模型 |
| `openclaw models status` | 查看当前模型配置状态 |
| `openclaw models set <provider/model>` | 设置默认模型 |
| `openclaw models scan` | 扫描可用模型 |
| `openclaw models auth login` | 登录/配置模型供应商授权 |

### 消息与渠道

| 命令 | 说明 |
| ---- | ---- |
| `openclaw message send --target <会话> --message "内容"` | 发送消息 |
| `openclaw channels list` | 列出已配置渠道 |
| `openclaw channels add` | 添加渠道账号（WhatsApp/Telegram/Discord 等） |
| `openclaw channels login / logout` | 渠道登录 / 登出 |
| `openclaw pairing list` / `pairing approve` | 查看 / 批准配对请求 |
| `openclaw qr` | 显示配对二维码 |

### 会话与交互

| 命令 | 说明 |
| ---- | ---- |
| `openclaw tui` | 终端交互界面（`chat`/`terminal` 为其别名） |
| `openclaw sessions` | 查看会话列表 |
| `openclaw resume` | 恢复之前的会话 |
| `openclaw attach` | 附加到运行中的会话 |
| `openclaw memory search "关键词"` | 搜索记忆 |
| `openclaw agents list` | 查看智能体列表 |

### 技能与插件

| 命令 | 说明 |
| ---- | ---- |
| `openclaw skills list` | 列出已装技能 |
| `openclaw skills search / install <名称>` | 搜索 / 安装技能 |
| `openclaw skills update` | 更新技能 |
| `openclaw plugins list` | 列出已装插件 |
| `openclaw plugins install / uninstall <名称>` | 安装 / 卸载插件 |

### 自动化任务

| ---- | ---- |
| `/status` | 快速诊断 |
| `/config` | 持久化修改配置 |

### 常用全局参数

| 参数 | 说明 |
| ---- | ---- |
| `--profile <name>` | 多实例隔离，状态存于 `~/.openclaw-<name>` |
| `--dev` | 开发模式，状态隔离到 `~/.openclaw-dev`，网关端口 19001 |
| `--log-level <level>` | 覆盖日志级别 |
| `--no-color` | 关闭彩色输出 |
| `-V` / `--version` | 查看版本 |
