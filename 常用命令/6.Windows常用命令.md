# Windows 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 文件与目录

| 命令 | 说明 |
| ---- | ---- |
| `dir` | 列出目录内容 |
| `cd <路径>` | 切换目录 |
| `md <目录名>` | 创建目录 |
| `rd /s /q <目录名>` | 删除目录及内容 |
| `copy / move / del` | 复制 / 移动 / 删除文件 |

## 2. 网络相关

| 命令 | 说明 |
| ---- | ---- |
| `ipconfig` | 查看网络配置（`/all` 详细） |
| `ipconfig /flushdns` | 清空 DNS 缓存 |
| `ping <地址>` | 测试连通性 |
| `tracert <地址>` | 路由跟踪 |
| `netstat -ano` | 查看端口占用 |
| `taskkill /pid <PID> /f` | 强制结束进程 |

## 3. 系统相关

| 命令 | 说明 |
| ---- | ---- |
| `tasklist` | 查看进程列表 |
| `sfc /scannow` | 系统文件检查修复 |
| `chkdsk <盘符>: /f` | 磁盘检查修复 |
| `systeminfo` | 查看系统信息 |

## 4. PowerShell 实用命令

| 命令 | 说明 |
| ---- | ---- |
| `Get-Process` | 查看进程 |
| `Get-Content xxx.txt` | 查看文件内容 |
| `Select-String -Pattern "xxx"` | 文本搜索（类似 grep） |
