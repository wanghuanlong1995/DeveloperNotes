# Qt 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 构建相关

| 命令 | 说明 |
| ---- | ---- |
| `qmake xxx.pro` | 生成 Makefile |
| `mingw32-make`（或 `make`） | 编译项目 |
| `qmake -project` | 由源码生成 .pro 文件 |

## 2. 部署相关

| 命令 | 说明 |
| ---- | ---- |
| `windeployqt xxx.exe` | Windows 下自动拷贝依赖 DLL |
| `macdeployqt xxx.app` | macOS 下打包依赖 |
| `linuxdeployqt xxx` | Linux 下打包依赖 |

## 3. 工具链相关

| 命令 | 说明 |
| ---- | ---- |
| `moc xxx.h -o moc_xxx.cpp` | 处理含 Q_OBJECT 的头文件 |
| `uic xxx.ui -o ui_xxx.h` | 将 .ui 转为头文件 |
| `rcc xxx.qrc -o qrc_xxx.cpp` | 编译资源文件 |
| `lupdate xxx.pro` | 提取翻译字符串 |
| `lrelease xxx.pro` | 编译翻译文件 .qm |
