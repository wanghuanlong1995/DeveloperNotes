# linux 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 文件与目录

| 命令 | 说明 |
| ---- | ---- |
| `ls -la` | 列出目录内容（含隐藏文件） |
| `cd <路径>` | 切换目录 |
| `mkdir -p a/b/c` | 递归创建目录 |
| `cp -r 源 目标` | 复制（-r 递归） |
| `mv 源 目标` | 移动 / 重命名 |
| `rm -rf <目录>` | 强制递归删除（慎用） |
| `find /path -name "*.log"` | 按名称查找文件 |

## 2. 文本处理

| 命令 | 说明 |
| ---- | ---- |
| `cat / less xxx` | 查看文件内容 |
| `grep -rn "xxx" ./` | 递归搜索文本 |
| `tail -f xxx.log` | 实时查看日志 |
| `wc -l xxx` | 统计行数 |

## 3. 进程与系统

| 命令 | 说明 |
| ---- | ---- |
| `ps -ef \| grep xxx` | 查找进程 |
| `top` / `htop` | 动态查看资源占用 |
| `kill -9 <PID>` | 强制结束进程 |
| `df -h` | 查看磁盘空间 |
| `du -sh <目录>` | 统计目录大小 |
| `systemctl status/start/stop <服务>` | 管理服务 |

## 4. 权限与压缩

| 命令 | 说明 |
| ---- | ---- |
| `chmod +x xxx` | 赋予执行权限 |
| `chown user:group xxx` | 修改属主 |
| `tar -zxvf xxx.tar.gz` | 解压 tar.gz |
| `tar -zcvf xxx.tar.gz <目录>` | 压缩为 tar.gz |
