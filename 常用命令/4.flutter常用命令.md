# flutter 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 环境相关

| 命令 | 说明 |
| ---- | ---- |
| `flutter doctor` | 检查开发环境 |
| `flutter upgrade` | 升级 Flutter SDK |
| `flutter channel` | 查看/切换渠道 |
| `flutter config --list` | 查看配置 |

## 2. 项目相关

| 命令 | 说明 |
| ---- | ---- |
| `flutter create <项目名>` | 创建新项目 |
| `flutter devices` | 查看可用设备 |
| `flutter run` | 运行项目 |
| `flutter run -d <设备ID>` | 在指定设备运行 |
| `flutter clean` | 清理构建产物 |

## 3. 依赖相关

| 命令 | 说明 |
| ---- | ---- |
| `flutter pub get` | 获取依赖 |
| `flutter pub add <包名>` | 添加依赖 |
| `flutter pub upgrade` | 升级依赖 |
| `dart run build_runner build` | 执行代码生成 |

## 4. 打包与分析

| 命令 | 说明 |
| ---- | ---- |
| `flutter build apk` | 打包 Android APK |
| `flutter build apk --release` | 打包 release 版 |
| `flutter build ios` | 打包 iOS |
| `flutter analyze` | 静态分析代码 |
