# npm 常用命令

> [返回 ReadMe](../ReadMe.md)

## 1. 项目与依赖

| 命令 | 说明 |
| ---- | ---- |
| `npm init -y` | 初始化项目（跳过提问） |
| `npm install` | 安装全部依赖 |
| `npm install <包名>` | 安装包 |
| `npm install <包名> -D` | 安装开发依赖 |
| `npm uninstall <包名>` | 卸载包 |
| `npm update` | 更新依赖 |

## 2. 脚本运行

| 命令 | 说明 |
| ---- | ---- |
| `npm run <脚本名>` | 执行 package.json 中的脚本 |
| `npm run dev` | 启动开发环境（按项目而定） |
| `npm run build` | 构建生产版本（按项目而定） |
| `npx <命令>` | 临时执行包命令，无需全局安装 |

## 3. 查看与维护

| 命令 | 说明 |
| ---- | ---- |
| `npm ls` | 查看已安装依赖树 |
| `npm outdated` | 查看过期依赖 |
| `npm audit` | 检查安全漏洞 |
| `npm cache clean --force` | 清空缓存 |
| `npm config set registry https://registry.npmmirror.com` | 切换国内镜像源 |
